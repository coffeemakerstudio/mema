# Mema Recipe Example

This directory contains boilerplate for a Mema runtime recipe. A recipe
package installs one shell recipe into `/etc/mema/recipe`.

- `recipe.sh` defines the version functions and metadata.
- `template_base.sh` is a reference implementation of the runtime contract.
- `control` is legacy Debian metadata; package metadata is generated by
  `../build.sh`.

Copy the example into `recipes/<tool>/` and provide real upstream SHA-256
values before calling `mema_download`.
