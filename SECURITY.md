# Security

Please report security vulnerabilities in Mema privately to
[mema-security@lupricht.net](mailto:mema-security@lupricht.net). Do not file
sensitive vulnerability details in public issues or discussions before
coordinating disclosure with the maintainers. Include the Mema version, affected
component, impact, and a minimal reproduction where possible. Avoid including
real credentials or private user data.

For general project or package support, use
[mema@lupricht.net](mailto:mema@lupricht.net). Do not use the general support
address for confidential vulnerability reports.
